# Travel Medicine Quiz

A small Flask quiz app (in Portuguese) testing knowledge of travel medicine —
vaccines, common traveler illnesses, and basic precautions.

## Setup

```bash
pip install flask
python app.py
```

Then open http://localhost:5000 and click through the quiz.

## Structure

- `app.py` — routes and the question bank
- `templates/` — Jinja templates (`index`, `question`, `results`)
- `static/style.css` — styling
